# Shelfwise roadmap

- [x] Design system (pastel glass tokens, fonts)
- [x] App shell + nav (Dashboard, Catalog, Scan, History)
- [x] Book catalog: add/edit copies/delete, search + filters, QR generation & download
- [x] QR camera scanning (html5-qrcode) with manual ID fallback
- [x] Issue/return with validation (unknown ID, no copies, duplicate issue, invalid return)
- [x] Transaction history with filters + CSV export
- [x] Admin stats: total / available / issued / overdue + days overdue
- [ ] Lovable Cloud backend (Postgres tables, RLS, server-side validation) — enabling failed, retry needed
- [ ] Librarian auth (login + roles)
- [ ] AI bonus: natural-language search / library assistant
